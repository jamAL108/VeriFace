# veriface

A technology to detect whether a videos is a deepfake edit or Real . In this we are using Technologies such as CNN and vgg16 to train our model .


## Features

- Verify whether the video is deepfake or edited
- Verify any youtube/ instagram video clip
- Trim the video accordingly
- Deepfake games for timepass until the model comes up with the result

## Tech Stack

**Client:** NextJS, Redux, TailwindCSS

**Server:** Flask, CNN, OpenCV, ytvideodownload


## Dataset

4000+ Videos of celebrity from forensics++ including deepfake and also original videos.
## Model


![image](https://github.com/user-attachments/assets/f60d2e99-00cd-4775-b09f-8f60c8fc8db4)
implemented vgg16 which is best option for image classification and fine tuned the model with 4000 videos dataset
